# SecureChat — Hybrid Cryptography CNS Portfolio

Responsive multi-page engineering portfolio for **SecureChat — Secure Multi-Client Chat Using Hybrid Cryptography**, built with React, TypeScript, Vite, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## GitHub Pages Deployment

The workflow at `.github/workflows/deploy.yml` builds the site with `GITHUB_PAGES=true` (`/CNS_Portfolio/` base path) and deploys `dist/` to GitHub Pages whenever changes are pushed to `main`.
